# RT-TDDFT collision pilot

## Status and objective

This directory prepares finite ice-cluster inputs for Octopus and runs target
ground-state and unperturbed time-propagation controls. Input preparation is
tested on both accepted ice phases. Octopus 16.4 is installed locally; an ice-derived single-water target
completed GS and TD execution. This coarse check warned of incompletely
converged states and does not establish physical accuracy. See
[installation and checks](INSTALLATION.md). Collision propagation is an incomplete
fragment, not an executable calculation. Embedding, channel analysis, collision
results, and transport tables remain unimplemented. RT-TDDFT is a candidate
to evaluate, not an adopted validated production model.

## Prepare and run

Use a Python environment containing NumPy and SciPy from the root requirements.
Commands below run from the repository root. Activate the installed solver
with `source physics/low_energy/RT_TDDFT/activate_octopus.sh`.

```bash
python -m physics.low_energy.RT_TDDFT.prepare \
  --phase amorphous_lda_80k --replica 0 --center 0 --molecules 5 \
  --spacing 0.3 --padding 6 --dt-au 0.02 --steps 100 \
  --energy-ev 1000 --impact 1 --separation 15 \
  --output physics/low_energy/RT_TDDFT/cases/amorphous_5water

python -m physics.low_energy.RT_TDDFT.run \
  --case physics/low_energy/RT_TDDFT/cases/amorphous_5water \
  --output physics/low_energy/RT_TDDFT/runs/amorphous_5water \
  --executable "$HOME/.local/opt/octopus-16.4/bin/octopus"
```

Use `--phase hexagonal_ih_100k` for ice Ih. `--replica` and `--center` are
zero-based. The center is the OHH record index in the registered snapshot,
not an inferred nearest-neighbor topology. Extraction supports the current
orthorhombic snapshots and rejects other cell shapes. Molecules are selected
by oxygen distance with deterministic tie ordering. Increase `--molecules`
with the same center to obtain nested quantum regions.

The two retained `examples/*_5water/` input bundles were generated by these
settings from the accepted sources. Each contains:

- `cluster.xyz`: intact water molecules, translated and periodically unwrapped.
- `manifest.json`: source and input hashes, selected molecule indices, explicit
  units, transformation, and H+ trajectory metadata.
- `gs.inp`: neutral finite-target ground state, frozen nuclei.
- `control_td.inp`: unperturbed frozen-target propagation using its GS restart.
- `collision.fragment`: documented moving-projectile settings only. The runner
  does not execute this fragment.

The sample grid, padding, time step, and short control duration are starting
settings, not converged recommendations. They use Octopus's bundled standard
LDA pseudopotentials and matching default XC; this is a numerical setup check,
not a validated charge-transfer approximation. Preserve the solver version,
pseudopotential identities and logs when assessing physical results. Oxygen
core electrons are not explicitly propagated by these target inputs.

The runner refuses existing output directories and changed input hashes. It
records executable identity, version, logs, and exit codes. A zero exit status
means execution completed, not that the SCF, energy drift, or electronic
physics passed validation. The GS and control run sequentially in one fresh
directory to share the restart. The runner does not configure MPI or submit
scheduler jobs; the first tiny serial case avoids an unmeasured allocation.

### Remaining collision prerequisite

Prepare and verify neutral H2O plus bare H+ as the incoming electronic state.
An unconstrained ground-state calculation of their combined +1 system can
transfer an electron before impact. `ExcessCharge = 1` fixes total electron
number, not which fragment holds the charge. The fragment deliberately has no
complete geometry, restart, or absorber specification until this initialization
is resolved. Its trajectory metadata uses nonrelativistic H+ kinematics and
total projectile energy. No C/O/S calculation is silently substituted with a
bare effective charge.

Next: converge the target controls, implement and check the incoming-state
initialization, then converge
the collision box, continuum treatment, and channel analysis. A gas-phase
reference geometry and benchmark data still need to be supplied separately.

### Solver documentation used

Input generation targets the Octopus 16.4 documentation:
[coordinates](https://octopus-code.org/documentation/16/variables/system/coordinates/coordinates/),
[box half-lengths](https://octopus-code.org/documentation/16/variables/mesh/simulation_box/lsize/),
[velocities](https://octopus-code.org/documentation/16/variables/system/velocities/velocities/),
[constant-velocity ions](https://octopus-code.org/documentation/16/variables/time-dependent/propagation/ionsconstantvelocity/),
and [TD output](https://octopus-code.org/documentation/16/variables/time-dependent/td_output/).
Constant-velocity ion motion is marked experimental by Octopus. These pages
establish input syntax, not scientific validation of this pilot.

The first calculation must establish whether an existing solver can resolve
capture, target excitation, and continuum emission for H+--H2O encounters.
Test one required C, O, or S charge state before committing to extensive ice
sampling. Do not extrapolate the dielectric RPWBA or CTMC tables to produce
these results.

## Shared ice inputs

Use the existing [material library](../../../models/ice/README.md)
as the sole source of ice configurations:

- Amorphous: `models/ice/epsr_lda80k/artifacts/collision_structures.json`
  (one published neutron-constrained EPSR LDA realization at 80 K).
- Hexagonal: `models/ice/hexagonal_ih_100K_experimental/collision_structures.json`
  (three NEP-MB-pol-equilibrated, proton-disordered ice-Ih replicas at 100 K).

Resolve paths through the registries, require `collision_ready: true`, and
verify registered SHA-256 hashes before extraction. Preserve complete water
molecules across periodic boundaries, original molecular geometries, phase,
cell, source identity, and selected molecule IDs. Record the extraction and
coordinate transformations so each collision input can be reproduced.
Do not duplicate or relax the shared source structures. The amorphous input
is an EPSR realization, not an MD-equilibrated snapshot.

Start with a local water molecule and nested clusters from each accepted
phase. An isolated water reference in the published benchmark geometry is
also needed; an ice-distorted molecule alone is not a like-for-like gas-phase
benchmark. A finite unembedded cluster is not a validated bulk-ice model.

## Minimal decision test

1. Specify total projectile kinetic energy and energy per nucleon explicitly,
   using the shared masses in `physics/constants.py`. The intended coverage
   is 100 eV--100 keV, but its per-ion/per-nucleon convention remains unresolved.
   Specify initial projectile charge and electronic state. C/O/S charge states
   have not yet been selected.
2. Check isolated target excitation and ionization energies and projectile
   charge-state energetics before collision propagation.
3. Benchmark H+--water at selected published energies and geometries. Then
   test extension toward 100 eV; do not label that extension validated by the
   higher-energy benchmark. Initially freeze target nuclei and document the
   prescribed projectile trajectory.
4. Compare charge-state/channel analysis against references. Distinguish
   mean electron populations from event probabilities. Capture, excitation,
   and emission can coexist; retain joint outcomes where accessible.
5. Establish convergence with spatial representation, time step, initial and
   final projectile separation, continuum boundaries, and analysis region.
   Account for outgoing electron flux and for externally supplied work when
   using a prescribed trajectory. Report numerical error separately from
   physical-model disagreement; set accuracy requirements before accepting
   the solver.
6. Repeat a small test for one required heavy-ion charge state, including its
   active projectile electrons. A successful proton test is insufficient to
   establish applicability to partially stripped C, O, or S.

Proceed to ice embedding and encounter ensembles only if these tests support
the required observables at feasible cost. Failure to identify channels or
converge them is a reason to reconsider the solver, not to generate tables.

## Nuclear motion and ice extension

After the electronic test, allow projectile deflection and target nuclear
motion. Ehrenfest dynamics is a candidate mean-force treatment; it does not
automatically reproduce separate nuclear trajectories for different electronic
outcomes. Resolve recoil, vibration, and fragmentation where relevant.

Use the shared mechanical model only through a defined coupling to the quantum
region. Derive the energy and force partition before combining models; do not
add NLH or other mechanical forces over interactions already supplied by the
quantum calculation. NEP-MB-pol does not itself provide electronic channels
or a general projectile--water interaction. Converge quantum-region size and
embedding before interpreting cluster results as ice observables.

Only subsequently average over impact parameters, orientations, and distinct
ice environments to derive transport inputs with uncertainty. No transition
to the higher-energy workflow is prescribed until overlap has been validated.

## Reference calculations

- Hong et al. (2016), *Physical Review A* **93**, 062706,
  [doi:10.1103/PhysRevA.93.062706](https://doi.org/10.1103/PhysRevA.93.062706):
  H+--water TDDFT coupled to molecular dynamics, 1--1000 keV. This range does
  not establish accuracy at 100 eV or for C/O/S.
- Mada et al. (2007), *Physical Review A* **75**, 022706,
  [doi:10.1103/PhysRevA.75.022706](https://doi.org/10.1103/PhysRevA.75.022706):
  low-energy charge transfer and excitation. Obtain the numerical reference
  data and exact calculation conditions before comparison. Ionization needs
  an independent reference; this citation alone does not validate it.

No reference curves have been digitized or numerically reproduced here.
